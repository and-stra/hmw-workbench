## Viewmodel composition

See [docs/viewmodel.md](../viewmodel.md) for the full rule and evidence. In short:

- Weapon JSON `handModel` may be the placeholder `viewmodel_base_viewhands`; HMW's
  `custom_teams.gsc` replaces it per faction/weapon class with `self setviewmodel("<viewhands>")`.
- The weapon xmodel root bone (`j_gun` for the AW crossbow, `tag_weapon` for HMW weapons) is attached to
  the hands' `tag_weapon` bone. `gunTransform = inverse(gunRootWorld) * handsTagWeaponWorld`.
- First-person origin is the hands `tag_view` bone (fallback `tag_camera`/`tag_cambone`), X forward,
  Z up, FOV default 65, near 0.02.

## Implementation

- `src/assets/weapon.*`: weapon JSON reader (gunModel/worldModel/handModel/camo override/animOverrides).
- `src/scene/viewmodel.*`: loads weapon + hands, chooses the hands model (explicit/weapon/faction), computes
  the attachment transform, combined bounds and first-person origin.
- Renderer: per-model world transform, sRGB colour textures, linear lighting + gamma, exposure.
- UI: selecting a weapon loads it; Hands dropdown; orbit / first person radio; viewmodel FOV and exposure;
  warnings (missing hands/textures). Selecting an xmodel still uses the M1 single-model view.
- CLI: `-weapon <name>`, `-hands <model>`, `-view orbit|firstperson`, `-exposure <n>`, plus the M1 flags.
